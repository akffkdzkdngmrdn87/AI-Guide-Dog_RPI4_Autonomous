# 자율주행 AI 안내견 로봇 (AI Guide Dog) 하드웨어 제원 및 시스템 통합 백서

**작성일자:** 2026년 4월 23일
**프로젝트 책임자:** J2W
**수석 엔지니어:** J2W

본 문서는 라즈베리파이 4와 아두이노 우노를 융합한 4륜 스키드 스티어링(Skid-Steering) 기반의 모바일 로봇을 ROS 2 Humble 환경에서 제어하고, RViz2를 통한 2D 매핑 및 Nav2 자율주행을 구현한 시스템 아키텍처 및 트러블슈팅에 대한 기술 보고서입니다.

---

## 제 1장: 모바일 로봇 하드웨어 상세 제원

자율주행 시스템의 내비게이션 스택(Nav2) 설정을 위한 정확한 기구학적(Kinematics) 제원 및 컴퓨팅 자원은 다음과 같습니다.

### 1. 물리적 기구학 제원 (Physical Kinematics)
* **전장 (Length):** 0.27m (270mm) - Nav2 로봇 점유 영역(Footprint) 설계의 기준 수치로 적용되었습니다.
* **윤거 (Track Width):** 0.15m (150mm) - 좌우 바퀴 중심 간의 거리입니다.
* **축거 (Wheelbase):** 0.13m (130mm) - 전륜과 후륜 축 간의 거리입니다.
* **타이어 지름:** 0.066m (66mm) - 표준 타이어 규격이며, 적용된 광학식 엔코더(20 Ticks/Rev) 기준 1틱당 이동 거리는 약 0.01036m로 산출됩니다.
* **슬립 보정 계수 (Slip Factor):** 실내 매끄러운 바닥 환경에서 발생하는 모터의 회전 손실을 보정하기 위해 `SLIP_FACTOR = 0.95`를 적용하였습니다.

### 2. 컴퓨팅 및 제어 코어 (Computing & Control Core)
* **메인 프로세서 (Main Processor):** Raspberry Pi 4 (4GB RAM) - Ubuntu OS 기반 ROS 2 Humble 미들웨어를 구동하며, SLAM 알고리즘 및 Nav2 연산을 전담합니다.
* **하위 제어기 (Microcontroller):** Arduino Uno + L293D 모터 드라이버 쉴드 - 실시간 모터 PWM 제어 및 하드웨어 센서 인터럽트 처리를 수행합니다.
* **학습 서버 (AI Training Server):** NVIDIA GeForce RTX 4070 12GB VRAM 탑재 워크스테이션 - 딥러닝 모델(CNN, LLM)의 오프라인 학습을 전담합니다.

### 3. 센서 시스템 (Sensor System)
* **2D 라이다 (LiDAR):** SLLidar (지상고 15cm 위치) - 2D 점군(Point Cloud) 데이터 기반 매핑 및 주요 장애물 회피에 사용됩니다.
(제품명 : SLAMTEC RPLIDAR C1 LiDAR)
* **관성 측정 장치 (IMU):** MPU-6050 - 스키드 스티어링 방식의 제자리 회전 시 발생하는 마찰 오차 및 방위각(Yaw) 보정에 활용됩니다.
* **초음파 센서 (Ultrasonic):** HC-SR04 배열 3개 (지상고 3cm 위치) - 라이다의 스캔 평면 하단에 위치한 사각지대 장애물 탐지 및 긴급 제동(Emergency Brake) 목적으로 사용됩니다.
* **광학식 엔코더 (Encoder):** 각 모터에 장착된 4개의 분해능 20 Ticks/Rev 엔코더를 통해 휠 오도메트리(Wheel Odometry)를 산출합니다.
* **비전 센서 (Camera):** Raspberry Pi Camera Rev 1.3 - 향후 비전 기반 행동 복제(Behavioral Cloning) 및 자율주행 학습 모델의 시각 데이터 수집을 위해 장착되었습니다.

### 4. 전력 공급 시스템 (Power System)
* **배터리 사양:** KLIFE PD-Q2 고속 충전 보조배터리 2기 (10000mAh, 37Wh).
* **공급 출력:** Type-C 5V/3A, 9V/2.22A, 12V/1.67A.
* **전력망 분리 설계:** 메인 프로세서(라즈베리파이)와 구동부(아두이노 및 모터)의 전력망을 두 개의 독립된 배터리로 물리적으로 분리하였습니다. 이는 모터 기동 및 과부하 시 발생하는 전압 강하(Brownout) 현상으로 인한 메인 프로세서의 시스템 재부팅(Reset)을 원천적으로 차단하기 위한 설계입니다.

## 제 2장: 시스템 통합 과정의 문제 해결 (Troubleshooting)

### 1. Nav2 제어기 비정상 종료 현상 (ZeroDivision & Extrapolation Error)
* **현상:** RViz2 환경에서 `2D Pose Estimate`는 정상 동작하나, Nav2 목적지(Goal) 설정 시 TF 프레임이 깨지며 메인 프로세스가 강제 종료(SIGKILL)되는 현상이 발생했습니다.
* **원인:**
  1. 오도메트리 노드(`real_odom_publisher.py`) 내에서 변수 초기화 전 엔코더의 비동기 하드웨어 인터럽트가 수신되어 발생하는 경쟁 상태(Race Condition) 오류입니다.
  2. 로봇의 위치 오차 신뢰도를 나타내는 공분산 행렬(Covariance Matrix) 데이터가 누락되어, DWB 로컬 플래너 연산 중 0으로 나누기(ZeroDivision) 오류가 발생했습니다.
* **해결 방안:** 변수 선언 위치를 GPIO 인터럽트 활성화 이전으로 재배치하였으며, 확장 칼만 필터(EKF) 설계 기준에 맞춰 평면 주행 모바일 로봇에서 사용하지 않는 축(Z축, Roll, Pitch)의 공분산 값에 `1e6`의 매우 큰 값을 할당하여 연산 안정성을 확보했습니다.

### 2. RViz2 오도메트리 회전 오차 (Phantom Rotation)
* **현상:** 물리적 로봇은 정지 상태이나, RViz2 상에서 로봇의 TF 프레임 및 라이다 점군 데이터가 지속적으로 회전하는 현상이 발생했습니다.
* **원인:** MPU-6050 센서의 초기 지구 중력 오차 및 제조상 발생하는 자이로 바이어스(Gyro Bias)를 영점 조절(Calibration)하지 않은 것이 원인입니다.
* **해결 방안:** 아두이노의 `setup()` 초기화 함수 내에 2초간 500회에 걸쳐 센서 데이터를 수집 및 평균화하는 영점 조절 알고리즘을 추가하고, 산출된 오차값(`gyro_z_offset`)을 실시간 데이터 연산 시 차감하여 보정하였습니다.

### 3. MPU-6050 센서 통신 데드락 (Deadlock) 및 결함 진단
* **현상:** I2C 버스 스캔을 통해 센서 주소(`0x68`)는 인식되나, 데이터가 고정되거나 비정상적인 노이즈 값만 출력되는 현상이 발생했습니다.
* **분석 및 진단:**
  1. 기계적 진동으로 인한 고주파 노이즈를 억제하기 위해 센서 내장 디지털 저역 통과 필터(DLPF)를 10Hz 대역폭으로 설정했습니다.
  2. 통신 데드락 해소를 위해 하드웨어 강제 초기화 레지스터(`0x80`) 쓰기를 시도했습니다.
  3. 센서 원시 데이터를 시리얼 플로터로 출력하여 Z축 가속도가 지구 중력(1G, 약 16384)을 정상적으로 측정하는지 테스트했습니다.
* **해결 방안:** 소프트웨어적 디버깅 수행 결과 Z축 1G 측정이 불가능한 물리적 MEMS 구조물 파손으로 진단되어, 센서 하드웨어를 신규 교체하여 문제를 해결했습니다.

## 제 3장: 향후 연구 및 시스템 확장 로드맵 (VLA Integration)

기존 2D 라이다에 의존하는 점유 격자(Occupancy Grid) 기반 주행을 넘어, 비전-언어-행동(Vision-Language-Action, VLA) 모델을 융합한 자율주행 고도화 계획입니다.

### Phase 1: 행동 복제 (Behavioral Cloning) 학습 데이터 수집
* **목표:** 전문가(운영자)의 수동 조작 주행 궤적 및 회피 기동 로직을 딥러닝 모델의 훈련 데이터로 확보합니다.
* **방법론:** ROS 2의 `rosbag2` 및 `cv_bridge` 패키지를 활용하여 조향 입력 데이터(Twist)와 라즈베리파이 전방 카메라의 영상 프레임(Image)을 타임스탬프 기반으로 동기화 수집합니다.

### Phase 2: 분산 컴퓨팅 기반 모델 학습
* **목표:** 수집된 주행 데이터를 기반으로 환경 인지 및 조향 제어 가중치를 추론하는 신경망을 생성합니다.
* **방법론:** 라즈베리파이에서 수집된 데이터를 고성능 연산 서버(RTX 4070)로 전송한 후, PyTorch 프레임워크 기반의 합성곱 신경망(CNN)을 학습시켜 종단간(End-to-End) 자율주행 가중치 파일(`.pt`)을 도출합니다.

### Phase 3: 거대 언어 모델(LLM) 기반 자연어 명령 체계 구축
* **목표:** 음성 기반 자연어 지시를 인식하고 상황에 맞는 주행 경로를 동적으로 생성하는 시스템을 구축합니다.
* **방법론:**
  1. 스마트폰과 블루투스 연동을 통해 수신된 음성 명령을 STT(Speech-to-Text) API로 문자화합니다.
  2. 텍스트 데이터를 학습 서버의 EXAONE 등 LLM 모델에 입력하여 의도를 파악합니다.
  3. LLM이 안전성이 검증된 형식의 JSON 웨이포인트(Waypoint) 지시서 (예: `{"action": "navigate", "target": "water_purifier", "x": 3.5, "y": -1.2}`)를 생성하도록 프롬프트 엔지니어링을 적용합니다.
  4. 생성된 JSON 좌표를 엣지 디바이스(라즈베리파이)가 수신하여 기존 비전 회피 주행 모델과 결합, 목적지에 도달하도록 구현합니다.
